# ReSetAD

**Learning Reliable References from Image Sets for Anomaly Detection**

[English](README.md) · [论文原稿](docs/paper.pdf) · [详细实验设置](docs/EXPERIMENT_SETTINGS.md) · [环境与复现](docs/SETUP.md) · [结果与版本差异](docs/RESULTS.md)

ReSetAD 面向无标签目标图像集合的零样本异常检测与定位。模型以冻结的 DINOv2 提取特征，通过参考图像之间的对应关系估计局部参考可靠性，再将可靠性惩罚加入匹配代价，在参考选择之前抑制不可靠匹配。推理期间参数固定，不需要文本提示或经过确认的正常支持图像。

本仓库整理自提供的 **DINOv2-L/14、518×518、VisA 源域实验快照**，包含代码、学习推理头、配置、任务计划和已有结果；内部实现名为 RR-Rank。随附论文为投稿稿件，不表示已经被会议录用。

## 核心设置

| 项目 | 本快照设置 |
|---|---|
| 骨干 | 官方非 register 版 DINOv2 ViT-L/14，全程冻结，FP32 |
| 输入与网格 | 518×518；37×37 patch；18×18 参考锚点 |
| 特征 | 第 6、12、18、24 层，1、3、5 窗口池化，共 12 分支 |
| 可训练参数 | 90,126 |
| 源数据 | VisA 全部 12 类，10,821 张，合并原始 train/test；9,621 正常、1,200 异常 |
| 每次更新 | 两个 16 图参考上下文，共享 4 张查询图；查询不固定正常/异常比例 |
| 训练 | seed=17；6,036 步参考预训练 + 24,144 步联合训练 |
| 优化器 | AdamW，峰值学习率 2e-4，最低 2e-5；每阶段前 200 步线性预热，随后余弦衰减 |
| 匹配 | 可靠性惩罚 0.25；每分支/位置选取两个不同参考图像 |
| 目标推理 | 名义集合大小 20；分组种子 101、202、303；每次最多 4 张查询 |
| 融合与评分 | 三轮原始分辨率概率图逐像素平均，再取最高 1% 像素均值 |
| 硬件 | 论文记载单张 NVIDIA A100-SXM4 40 GB |

损失系数、参考污染分布、数据清单和评价定义见[详细实验设置](docs/EXPERIMENT_SETTINGS.md)。`configs/paper_settings.json` 为结构化参数说明，不覆盖已有训练配置。

## 获取与校验

```bash
git clone https://github.com/BojueGao/ReSetAD.git
cd ReSetAD
python tools/verify_source_release.py
```

校验只需要 Python 标准库，会验证原始清单中 79 个文件的 SHA256 并解析源码，不会训练模型或占用 GPU。新增发布文件列在 `provenance/publication_manifest.json`。

## 环境与权重

`requirements-observed.txt` 记录原服务器上的核心包版本，不是已验证的新环境安装锁文件。完整运行还需单独取得 DINOv2 实现及骨干权重、合法获取的数据集、数据清单和缓存及历史执行依赖，见[环境与复现](docs/SETUP.md)。

仓库提供 `result/rr_rank_v1/inference_model.pt`，为第 30,180 步、seed=17 的学习推理头，不包含官方 DINOv2 骨干。原代码保留服务器路径和完整性检查，现有监督脚本不能直接当作新机器上的一键训练入口。

## 论文与快照的范围

论文覆盖 13 个基准，在评测 VisA 时使用另行训练的 MVTec AD 源模型；本包只有 VisA 源模型及 12 个目标数据集指标，不含反向源模型。论文表格中的部分数字与包内 CSV 不同，例如 MVTec AD 图像 AUROC：论文 98.18%，CSV 94.08%。本仓库保留 CSV 原值，并在[结果说明](docs/RESULTS.md)中列出差异，不把稿件指标当作此次重新运行的结果。

本版本只有一个训练种子。方法使用目标集合的其他图像作为参考，效果依赖分组和正常外观覆盖；原快照还披露早期目标诊断曾影响方法开发。应按集合推理协议进行比较。
